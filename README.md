# NexoDocs

Agente corporativo inteligente baseado em RAG (Retrieval-Augmented Generation), desenvolvido para o Challenge Alura Agentes.

> 🚧 Projeto em desenvolvimento.

## Sobre o projeto

O NexoDocs tem como objetivo permitir que colaboradores consultem documentos corporativos utilizando linguagem natural e recebam respostas fundamentadas na base documental da organização.

## Objetivo

Construir um agente de inteligência artificial capaz de:

- processar documentos corporativos;
- dividir e preparar o conteúdo para recuperação;
- gerar embeddings;
- indexar o conhecimento em uma base vetorial;
- recuperar informações por similaridade semântica;
- responder perguntas utilizando RAG;
- apresentar as fontes utilizadas;
- evitar respostas inventadas quando a informação não estiver disponível;
- funcionar em ambiente de nuvem utilizando Oracle Cloud Infrastructure (OCI).
